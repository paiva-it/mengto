# Credits — photos, images and data

for the skills, libraries, fonts and icons.

- **Unsplash** photos are used under the [Unsplash License](https://unsplash.com/license). Each
  one is linked to its Unsplash page. The photographer is named wherever the photo could be
  traced. A few could not be, and those link to the image itself.
- **Skill demo assets** are bundled with the skill in [MengTo/skills](https://github.com/MengTo/skills)
  (MIT). Their own upstream photographer is not recorded there.
- **Made for this repo** are renders and procedural images created while building the page.
- **Natural Earth** data is public domain.

If you own one of these images and it is credited wrongly, or you want it removed, please open an issue.
